## 第一步：注册 Firebase（10 分钟）

1. 访问 <https://console.firebase.google.com>，用 Google 账号登录。
2. 点击「**Add project / 添加项目**」，名字随便取，例如 `nutrition-quiz`。
3. 关闭 Google Analytics（不需要）→ 创建项目。
4. 进入项目后，左侧菜单 → 「**Build → Firestore Database**」 → 「**Create database**」
   - 模式选 **Start in test mode**（30 天后会自动锁定，讲座当天足够用）
   - 区域选 `asia-east1`（台湾）或 `asia-southeast1`（新加坡），延迟最低
5. 左侧菜单 → 项目设置（齿轮图标） → 「**Your apps**」 → 点击 `</>` 图标添加 Web App
6. 给 App 取个名字，**不要勾选** Firebase Hosting，注册后会得到一段 config：

```js
const firebaseConfig = {
  apiKey: "AIzaSy....",
  authDomain: "nutrition-quiz.firebaseapp.com",
  projectId: "nutrition-quiz",
  storageBucket: "nutrition-quiz.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:xxxxx"
};
```

**复制这段 config，下一步要用。**

## 第二步：把 config 填到两个文件里

### A. 观众端 `膳食健康自测_联网版.html`

用记事本/VS Code 打开，搜索 `FIREBASE_CONFIG`，找到这段：

```js
const FIREBASE_CONFIG = {
  // apiKey: "...",
  // authDomain: "...",
  // projectId: "...",
  // appId: "...",
};
```

把上一步复制的 config 粘进去（去掉注释 `//`）。

### B. 讲者端 `膳食健康自测_大屏.html`

打开后在 `<body>` 末尾、`<script type="text/babel">` **之前**，添加一段：

```html
<script>
  window.__FIREBASE_CONFIG__ = {
    apiKey: "AIzaSy....",
    authDomain: "nutrition-quiz.firebaseapp.com",
    projectId: "nutrition-quiz",
    appId: "1:xxxxx"
  };
</script>
```

## 第三步：放宽 Firestore 安全规则（仅讲座当天）

Firebase Console → Firestore Database → **Rules** 标签，粘贴：

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /submissions/{doc} {
      allow create: if request.resource.data.keys().hasAll(['ts','answers','verdict']);
      allow read: if true;
      allow update, delete: if false;
    }
  }
}
```

发布。这样任何人都能匿名提交一份问卷，但谁也不能改/删。

## 第四步：部署观众端 H5 + 生成二维码

### 选项 1：GitHub Pages（推荐，免费永久）

1. 注册 <https://github.com> 账号
2. 创建一个新仓库，名字如 `quiz`
3. 上传 `膳食健康自测_联网版.html`，重命名为 `index.html`
4. 仓库设置 → Pages → Source 选 `main` 分支根目录 → 保存
5. 等 1 分钟，访问 `https://你的用户名.github.io/quiz/` 即可

### 选项 2：Vercel / Netlify（更快）

直接拖文件上传，3 分钟出链接。

### 生成二维码

把上面拿到的链接放进 <https://cli.im> 或 <https://www.qrcode-monkey.com>，下载 PNG，
插入 PPT 第 8 页右下角，加一行字「扫码 1 分钟参与」。

## 第五步：讲者端怎么用

讲座当天：

1. 演讲电脑用 Chrome / Edge **全屏**打开 `膳食健康自测_大屏.html`
2. 右下角 Tweaks 按钮 → 关闭「演示模式」→ 自动连接 Firebase
3. 顶部 LIVE 指示变红色脉冲 = 连上了
4. 演讲时大屏切到这一页即可

### 现场操作技巧

- 顶部 Tweaks 面板（隐藏式，不影响投影）：
  - **暂停接收**：讲到关键环节冻结画面
  - **重置数据**：上一场结束后清空
  - **视图切换**：综合仪表盘 / 大圆环聚焦 / 逐题榜单
  - **演示模式 + 模拟速度**：彩排时不需要真听众也能演

## 演示模式

如果想在没有 Firebase 的情况下排练讲稿：
- 大屏页打开后默认就是演示模式（顶部显示橙色圆点 + "演示模式"）
- Tweaks 里调「模拟速度」可以快进，看高量数据下的形态
- 排练完，关掉演示模式即可切到真实数据

## FAQ

**Q：现场没 WiFi 怎么办？**
A：让所有听众用手机 4G 即可。链接和 Firebase 都走 HTTPS。

**Q：Firebase 免费够用吗？**
A：免费额度每天 50000 次读 + 20000 次写，单场讲座 200 人 × 15 题远远用不完。

**Q：讲座结束后怎么导出数据？**
A：Firebase Console → Firestore → submissions 集合，可直接导出 JSON。

**Q：能否换成国内的腾讯云开发？**
A：可以，把 `submitToBackend` 函数和大屏的 `startFirebase` 改成腾讯云开发的 SDK 即可，结构一致。需要的话告诉我，我可以再出一份适配代码。

**Q：二维码扫了打不开？**
A：99% 是 GitHub Pages / Vercel 链接没用 HTTPS，或者域名拼错。先在自己手机上验证一遍。
