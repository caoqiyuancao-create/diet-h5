互动②：身心营养红绿灯 · 15题匿名自测

共15题，分为三组：

### A. 红灯题：警惕区，共5题

红灯题代表较明确的风险习惯，符合时计入较高风险分。

1. 经常不吃早餐，空腹到中午
2. 三餐总有一顿“随便凑合”
3. 每天喝含糖饮料或吃甜食 ≥1次
4. 每日蔬菜摄入量不足一拳头
5. 很少吃鱼或海鲜类食物

### B. 黄灯题：观察区，共5题

黄灯题代表需要留意和调整的习惯，符合时计入一般风险分。

1. 偶尔熬夜，导致第二天食欲差
2. 经常点重盐、重辣的外卖
3. 吃饭速度快，10分钟内解决
4. 每天喝水量不足1500ml
5. 加餐零食常选薯片、饼干类

### C. 绿灯题：保持区，共5题

绿灯题代表健康保护习惯，符合时计入保护分。

1. 每天吃早餐，且搭配营养均衡
2. 三餐定时定量，规律进食
3. 每天摄入足量的新鲜蔬菜和水果
4. 每周吃鱼或海鲜类食物2–3次
5. 主动少喝含糖饮料，多喝白水

每一题只让听众选：

**符合 / 不符合**

> 请根据最近2周的真实情况填写。家长，请以孩子最近2周的饮食和作息情况为准。

## 基础计分规则

把15题分成三组：

| 题目类型 | 题目数量 | 符合时计分     | 含义                         |
| -------- | -------- | -------------- | ---------------------------- |
| 红灯题   | 5题      | 每题 +2 风险分 | 明确需要调整的高风险习惯     |
| 黄灯题   | 5题      | 每题 +1 风险分 | 暂时不严重，但需要观察的习惯 |
| 绿灯题   | 5题      | 每题 +1 保护分 | 已经具备的健康习惯           |

设三个变量：

**R = 红灯题符合数量**
 **Y = 黄灯题符合数量**
 **G = 绿灯题符合数量**

再算一个总风险分：

> **风险分 P = 2R + Y**

| 结果              | 判定条件                 | 解释                                       |
| ----------------- | ------------------------ | ------------------------------------------ |
| **红灯 · 警惕区** | **R ≥ 3**，或 **P ≥ 6**  | 有多个高风险饮食/作息信号，需要优先调整    |
| **绿灯 · 保持区** | **P ≤ 1 且 G ≥ 3**       | 风险习惯很少，同时已经有比较稳定的健康习惯 |
| **黄灯 · 观察区** | 不属于红灯，也不满足绿灯 | 有一些可调整问题，但还没有达到明显警惕状态 |

### 黄灯 · 观察区

> 你目前有一些可调整的饮食或作息习惯。它们暂时不一定严重，但如果长期存在，可能会影响身高、眼睛、大脑状态、情绪稳定和免疫力。建议你从最容易做到的一项开始改变，比如每天多加一拳蔬菜、把含糖饮料换成白水、或把晚睡提前15分钟。

### 红灯 · 警惕区

> 你目前存在多个需要关注的饮食或作息信号。这不代表已经生病，而是提醒我们：身体和情绪可能正在承受额外负担。建议从一个最关键的习惯开始调整，例如规律早餐、减少含糖饮料、增加蔬菜和优质蛋白。如果孩子同时伴随明显睡眠、情绪、体重、发育或注意力问题，建议咨询医生或营养专业人员。
